# Calc Clicker
APCSA edition

## Concept
Long have the mathemeticians toiled in pain, bored beyond measure.
That is, until Calc Clicker was invented!
This champion of the classroom has finally
switched its domain from Math class to Computer Science, in an
even more helpful form. The classic game includes APCSA questions you must answer
every time you level up.

## Installation
Clone the repository and run it with Java.

## Usage
Answer the questions and enjoy the fun!
